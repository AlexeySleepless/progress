Прототип блока прогресс реализован как кастомный элемент со своим теневым DOM.

В верстке c атрибутами его можно указать следующим образом:
`<progress-bar value="50" animate="true"/>`.

Добавлять в DOM и манипулировать им и его аттрибутами можно так же, как и выполнять эти действия со стандартными элементами.

Для того, чтобы использовать его, нужно импортировать файл его объявления ProgressBar/ProgressBar.js в выполняемый js-файл.

Можно менять его цвета путем задания значений соответствующих css-переменных: --progressLine-color и --fullLine-color.
